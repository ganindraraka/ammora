# Ammora Launchpad — delivery outcomes

## Build a credible testnet launchpad with Ammora SDK
- Discover live launches through `AmmoraDataApiClient` and the official Ammora GIWA Sepolia deployment catalog.
- Show launch cards with token name, symbol, address, progress, market data, and status.
- Show token details with transparent metrics, contract links, and explicit testnet labeling.
- Provide wallet connection for GIWA Sepolia without asking for private keys or seed phrases.
- Provide an unsigned launch transaction preview showing SDK action, parameters, target factory, and required network.
- Keep interaction non-custodial and never auto-sign or auto-send a transaction.
- Link to the official Ammora explorer, docs, SDK package, and Ammora app.
- Support responsive desktop and mobile layouts.
- Explain the SDK integration and demo scope in a builder submission section.
- Include loading, error, empty, and unsupported-network states.

## Ship and prepare review
- Run the app on the managed Preview runtime and verify the production build.
- Save the delivered version to the canonical repository before handoff.
- Prepare a concise X post draft and open Ammora's builder submission flow after the site is published.
